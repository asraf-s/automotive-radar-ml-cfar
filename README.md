## Project Overview
This repository contains the complete scientific pipeline for the ET-CFAR project:
an Extra Trees Regressor that predicts the CA-CFAR scaling factor α per-cell from 8 local
noise statistics of the 77 GHz FMCW Range-Doppler map, enabling simultaneous 2D
range-velocity adaptive detection without replacing the CFAR structure.

**Key result:** CV R² = 0.919 (Extra Trees, best of 8 models benchmarked)
**α* range:** [1.5, 55.0] — 35× variation confirming fixed-α is inadequate

## Quick Start

```python
# 1. Generate a scene
from fmcw_simulator import FMCWSimulator, SceneConfig, Target
sim = FMCWSimulator()
scene = SceneConfig(targets=[Target(50, 15), Target(80, -8)],
                    snr_db=15, noise_type='rayleigh',
                    clutter_edges=True, seed=42)
rd, mask = sim.generate(scene)

# 2. Create the model first (run once: python evaluation.py), then load it
from extra_trees_cfar import ExtraTreesCFAR
model = ExtraTreesCFAR.load('et_cfar_model.pkl')

# 3. Detect
detections, threshold = model.detect_2d(rd)

# 4. Compare vs classical
from cfar_classical import cfar_2d_fast
det_ca, thr_ca = cfar_2d_fast(rd, variant='CA')
```

## 8-Feature Vector
| f_i | Feature | Physical Meaning |
|-----|---------|-----------------|
| f₀ | mean (μ) | Noise floor baseline |
| f₁ | variance (σ²) | Power spread |
| f₂ | skewness (γ₁) | Distribution asymmetry |
| f₃ | kurtosis (γ₂) | Heavy-tail indicator (most important) |
| f₄ | IQR | Robust spread |
| f₅ | max/mean | Heterogeneity / target contamination |
| f₆ | lead/lag ratio | Clutter-edge indicator (most important) |
| f₇ | CV (σ/μ) | Normalised variability |
